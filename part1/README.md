# Part 1 — Nature-Inspired Algorithm Synopses

**Deadline:** Friday 24 April 2026, 11:59pm AWST

## Structure

Each team member writes a synopsis (1–11 pages) on one nature-inspired optimisation algorithm, covering:

1. What problem does this algorithm solve vs existing approaches?
2. Why have previous attempts failed?
3. What is the new idea / novelty?
4. How is it demonstrated (experiments, proof, etc.)?
5. Results and validation?
6. Assessment of conclusions — would you use this algorithm for the bot?
